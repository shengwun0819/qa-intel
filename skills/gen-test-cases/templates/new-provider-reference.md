## 測試案例：<ticket-id> 新增 <整合對象名稱>

基本功能
1. 整合初始化成功（基本功能可用）
2. 主要操作路徑（依整合類型填入，例如：查詢、傳送、兌換）
3. 格式錯誤的輸入顯示對應提示
4. 不支援的操作類型顯示對應提示

資產 / 轉帳（若適用於幣種或帳戶整合）
1. 取得餘額 / 查詢資產
2. 基本轉帳
3. 最大值轉帳（只開啟確認頁，未送出）
4. 目標地址格式錯誤時顯示提示
5. 支援不同格式的目標地址

兌換 / Swap（若適用於服務商整合）
1. 主要幣對 floating rate
2. 主要幣對 fixed rate
3. Token → Coin（floating）
4. Coin → Token（fixed）
5. Token → Token（floating）

訂單 / 狀態驗證（若適用）
1. 狀態流轉符合預期（例如：進行中 / 完成 / 失敗 / 逾期）
2. 操作成功後進入紀錄頁，確認資料正確
3. 歷史詳細頁顯示資訊皆正確

Regression（其他既有整合）
1. 整合對象 A：主要路徑（可正常執行）
2. 整合對象 B：主要路徑（可正常執行）
3. 整合對象 C：主要路徑（可正常執行）

發佈前確認
1. 相關後端服務 / 依賴項目已部署至 production
2. 設定檔 / 版本清單已更新
3. Production 驗證：主要功能（查詢、操作、紀錄）正常運作
4. 確認手續費/收益機制符合預期（若適用）
